
# Click and Play

 A collection of classic mini-games bult with React.

## Current Features:

- **Tic-Tac-Toe** - a game of Tic-Tac-Toe, currently only locally playable. There is also a computer algorithm to play as an opponent. There is also a win / lose screen.

- **Minesweeper** - called *Bomb Clearer* on the site. This is a classic **easy** diffuclty game of Minesweeper. There is a timer that starts on first click and a win / lose screen.

## Running the Site

1. **Clone the repository**
   - Click the green **Code** button on the GitHub page
   - Copy the repository URL (HTTPS or SSH)
   - Run the following command in your terminal:
     `git clone <repository-url>`
   - Navigate into the project folder:
     `cd <project-folder>`

2. **Install dependencies**
   `npm install`

3. **Start the development server**
   `npm run dev`
   - Open the provided `localhost` URL in your browser
